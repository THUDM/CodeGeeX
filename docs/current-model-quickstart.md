# CodeGeeX Quickstart for Current Model Users

If you are arriving here for the first time, decide first whether you need the legacy 13B research release in this repository or one of the newer CodeGeeX model generations.

| What you want | Recommended starting point |
|---|---|
| The newest openly promoted model family | [CodeGeeX4](https://github.com/THUDM/CodeGeeX4) |
| The original multilingual 13B research model and HumanEval-X benchmark | This repository |
| IDE completion inside VS Code | `vscode-extension/README.md` |
| API-based usage examples | `api/README_zh.md` plus the example folders under `api/` |

## Minimal first-run path for this repository

1. Read the root `README.md` to confirm that this repository matches your target use case.
2. Follow the installation section if you need the legacy 13B model or the benchmark assets.
3. If you only want a modern coding assistant experience, prefer the newer CodeGeeX release linked above.
