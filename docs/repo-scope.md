# CodeGeeX Repository Scope

This repository primarily documents the original **CodeGeeX 13B multilingual code generation model**, its benchmark assets, and the surrounding extension / API materials from that release cycle.

## What is in scope here

- the legacy 13B model usage instructions;
- HumanEval-X benchmark materials;
- VS Code extension documentation from the same generation;
- API example projects and legacy deployment notes.

## What to check before opening issues or extending docs

| If you need... | Start here instead |
|---|---|
| the newest CodeGeeX model family | [CodeGeeX4](https://github.com/THUDM/CodeGeeX4) |
| modern IDE features tied to newer model releases | the latest model repo or product site |
| legacy benchmark assets or the original research paper context | this repository |

Keeping this distinction clear helps contributors avoid mixing legacy research docs with the newer model-generation workflows.
